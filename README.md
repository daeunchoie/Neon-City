# NEON WORLDS
Run locally (ES modules need a server, not file://):
    cd neon-worlds && python3 -m http.server 8000   # open http://localhost:8000
Test on phone: same Wi-Fi, open http://<your-computer-ip>:8000
Deploy: push this folder's contents to a GitHub repo, then Settings > Pages > Deploy from branch (main, / root).
